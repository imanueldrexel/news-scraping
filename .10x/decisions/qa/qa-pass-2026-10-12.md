## Lessons
- A Done-when listing only the cases a fix targets (elliptical follow-ups) can pass while the fix breaks the neighbouring case (a follow-up that changes topic). Probe the "alone" and "with context" pair for the inputs the old code already handled.
- "The next occurrence" semantics make every re-resolution of a time a bug: resolve a deadline once per run.
- A re-chunk scoped to "articles" misses queued rows that become articles later; scope a corpus migration by the rows it rewrites (chunks), not by the rows that happen to be served today.
- Word counts are a proxy for encoder tokens; measure the real tokenizer on a sample before claiming a window fits.
