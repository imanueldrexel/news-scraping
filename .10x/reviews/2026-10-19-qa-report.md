## Defects
1. **SYS-181 (P1, blocker for close).** `causal_check._refers_back` (`newscrawler/core/causal_check.py:295-308`) lends the previous sentence when the anaphor's subject shares any root with it. "Penurunan saham BBRI tersebut" shares "turun" with "IHSG turun 1 persen ...".
   - Source: "IHSG turun 1 persen pada Senin. Penurunan saham BBRI tersebut dipicu aksi jual asing."
   - Claim "IHSG turun karena aksi jual asing." is **kept**. Expected: refused (the source attributes BBRI's fall, not the IHSG's).
   - Fix: lend only to the side's subject words. A name in the claim's half that the anaphor's subject does not hold (IHSG vs BBRI) is not covered by the lent sentence.
2. **SYS-185 (P2).** `_DENIAL` (`causal_check.py:113`) is read only before the causal word.
   - "Anggapan bahwa harga tiket ... naik karena harga avtur melonjak **dibantah** maskapai." backs the flat claim.
   - "Maskapai **menyangkal** ..." does too (not listed).
   - Fix: read a denial anywhere in the link's sentence, both sides; add (me/di)nyangkal/sangkal.
3. **SYS-193 (P3).** `unbacked_end_times` (`source_check.py:652-659`) matches a clause with no content word before the opener by time alone. A fronted end ("Hingga 2026, pembekuan saham berlanjut.") skips the subject check.
   - Fix: for a fronted end, take the clause AFTER the time (to the next boundary) as the subject.
   - Also weak by design: one generic shared root ("saham") backs it ("Penjualan saham ritel hingga September 2026").
4. **SYS-177 (P2).** `_FUTURE_VERB` (`story_arc.py:349`) is a closed list. "dipastikan" and "dijanjikan" schedules in the latar are printed on 26/10 with a 22/10 source date.
   - Fix (structural, instead of growing the list): in the latar, a running span counts as narration only with a past marker in its clause (sebelumnya, lalu, sempat, sejak, telah/sudah). Anything else is judged as a schedule. Replay cost to measure: the 6 latar spans all carry "Sebelumnya, pada ...".
5. **SYS-144/145 (P3 tickets, real 0/5 regressions on held-out pairs).** `followup.refers_to_thread` (`newscrawler/web/followup.py:83-106`) removes object-phrase names before the own-subject test. When the follow-up's only name is in an object phrase ("terjadi **pada Garuda Indonesia**"), the unlisted adverb decides, which is SYS-144's exact original shape. Live (read-only), ALONE / KEPT / FALLBACK:
   - Antam -> "Apa yang harusnya dilakukan pemerintah terhadap Garuda Indonesia?": 3/5 / **0/5** / **0/5**;
   - Antam -> "Apa yang aslinya terjadi pada Garuda Indonesia?": 5/5 / **0/5** / **0/5**;
   - OJK -> "Apa yang mestinya terjadi pada Sritex?": 4/4 / 2/5 / 2/5;
   - IHSG -> "Kayaknya ada masalah di Waskita Karya, apa itu?": 5/5 / 4/5 / 4/5;
   - control, Fed -> "Bagaimana dampaknya ke rupiah?": 0/5 / 5/5 / 5/5.

   Fix to consider: an object-phrase name counts as the thread's object only when the reference word is a noun clitic (dampaknya, pengaruhnya), not an adverb-shaped -nya before the verb. Or: a name absent from the thread anywhere makes the follow-up its own unless the reference is a known effect/relation noun.
6. **SYS-146 (P3, minor).** `nya_words.possessive_root` (`newscrawler/web/nya_words.py:43-50`) strips "ditanya" -> "dita" (NOT_CLITIC lacks ditanya/menanya). An unlisted adverb becomes an anchor: "mestinya" -> "mesti", fts=0 on "Apa yang mestinya terjadi pada Sritex?".
7. **SYS-186 side effect (P3, fail-closed).** `_END_GAP` + `_END_POINT` (`source_check.py:603-608`) read the spatial "meluas hingga Riau pada akhir Oktober" as an end point. A true latar is refused as `date`.
