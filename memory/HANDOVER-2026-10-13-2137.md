## Key Decisions Made
- **Decision:** arcs inside the daily edition: 3-4 deep stories, ≤ 1,200 words, lookback adaptive up to 30 days, importance-first selection, a look-ahead only when an article states it.
  - **Context:** the owner chose this over a weekly synthesis, entity/theme tracks, or prose-only (AskUserQuestion).
  - **Rationale:** it keeps the 5-minute phone read. A one-off story gets "why it matters" instead of an arc.
- **Decision:** **pure prose, no labels.** No Berlanjut/Baru kicker, no Kronologi line, no "Agenda berikutnya" label.
  - **Context:** the PM recommended labels; the owner declined them.
  - **Rationale:** labels are the "pointiness" being removed. Continuity must be said in the prose (a prompt rule).
- **Decision:** NEWS_L1 vectors find the thread; the LLM confirms each timeline item (`alur`); code checks them. KB entities are not used in P0.
  - **Context:** the probe on 10-12's 6 leads. Vectors found real arcs for 4/6, and none for the genuinely new lobster ban. Entities returned 0 for concept stories and drifted ("Timur Tengah" linked IHSG to Houthi). A cosine of 0.70 over-includes; 0.80 cuts real history (Houthi 9 → 2 days).
  - **Rationale:** no cutoff separates "same thread" from "similar topic", so model confirmation plus guards. Entities return after the #315 merge.
- **Decision:** an in-edition stage with no thread store. The `_edition.stories` JSON in `newsletter_digests.categories` is P1's input (no migration).
  - **Rationale:** a `story_threads` table is a one-way door before the owner has seen arcs. NEWS_L1 is already in memory at 12:00.
- **Decision:** rollout: replace today's edition after the blind A/B (arcs win ≥ 4/5 days), keeping `NEWSLETTER_ARCS=0` as a byte-identical switch back. The owner chose this over sending both, or a hidden diary run.
- **Decision (scaled default, not owner-confirmed):** with 3-4 slots, "≥ 2 non-finance" becomes "≥ 1 when one qualifies". Flagged on SYS-149.
